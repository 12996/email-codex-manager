# PRD-001 项目文档管理体系

状态：active

## 背景

大型 vibe coding 项目需要稳定文档体系，帮助 AI 恢复上下文，并帮助人类追溯需求、文档结构、问题、决策和工作过程。

## 目标

- 文档分层明确：模板、记忆、需求、项目说明、问题、工作记录不混放。
- AI 能快速定位相关文档。
- 人类能追溯项目演进。
- 文档不过度碎片化。

## 范围

- 包含：`AGENTS.md`、`docs/README.md`、`docs/prd/`、`docs/project/`、`docs/templates/`、`docs/memories/`、`docs/issues/`、`docs/work/`
- 不包含：具体业务需求、具体业务架构、数据模型、一次性聊天流水

## 验收标准

- [x] `AGENTS.md` 是精简版 AI 导航协议。
- [x] `docs/README.md` 是文档总入口。
- [x] 每个核心目录有入口文件。
- [x] 信息归属清晰。
