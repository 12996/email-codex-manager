# issue-021 无2FA协议账号提链结算金额读取失败

状态：active
创建日期：2026-08-03
关联 change：CHG-103

## 现象

手动浏览器自动化并完成 2FA 的账号可以完成提链；无 2FA OTP-first 协议注册账号在试用资格
检查中已创建试用结算会话，但读取最终结算金额失败。

## 已知事实

- 本地补号账号状态不会参与 OpenAI 结算接口，因此 `unregistered` 不是该结算读取失败的原因。
- 页面文案只能证明结算流程后续一步失败，不能单独证明 AT 无效。
- 当前注册网络录制只覆盖注册与 session AT 获取，不包含提链/结算请求，不能据此补造 Auth 调用。

## 排查计划

1. 对一枚可提链的手动 2FA 账号和一枚失败的无2FA协议账号，在同一提链操作中分别录制网络请求。
2. 比较结算会话创建与最终金额读取请求的 URL、方法、状态码、请求上下文和脱敏响应结构。
3. 仅在差异由实际请求证实后，决定是补充浏览器初始化、修正提链检查器，还是修正协议注册流程。

不得记录或写入 AT、Cookie、代理凭据、CDP endpoint、OTP 或完整结算会话标识。
