# document-architecture.md

记录本项目的文档结构和目录职责。

| 目录 | 放什么 | 承载功能 |
|---|---|---|
| `docs/prd/` | PRD 和 PRD 索引 | 需求真相源 |
| `docs/changes/` | 日常需求、规则、结构或长期行为变更 | 变更闭环 |
| `docs/project/` | 文档结构、API、部署等项目级说明 | 项目说明 |
| `docs/templates/` | PRD、issue、work、handoff、test、decision 模板 | 格式复用 |
| `docs/memories/` | 项目风格、长期经验、重要决策 | 长期记忆 |
| `docs/issues/` | 缺陷、风险、排查和修复记录 | 问题追踪 |
| `docs/work/` | 工作索引、每日工作文档、日终交接 | 过程追踪 |
