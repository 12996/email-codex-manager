# CHG-043 补号列表长字段截断与复制

- 状态：merged
- 日期：2026-06-08
- 关联 PRD：PRD-002

## 背景

补号列表中邮箱、手机号、SMS API、邮箱验证码 API、公开验证码 Key 等字段可能过长，导致宽表阅读成本高。用户要求列表字段有最大显示长度，超出后在旁边提供复制按钮，复制该字段完整原始值。

## 变更

- 补号列表前端新增字段显示长度配置 `tableFieldLimits`。
- 邮箱、手机号、SMS API、邮箱验证码 API、备注、开通方式、时间、公开验证码 Key 等单元格统一使用截断渲染。
- 当字段原文超过对应最大长度时，单元格旁显示“复制”按钮。
- 点击“复制”会复制该账号对应字段的完整原始值；剪贴板不可用时回退到浏览器 `prompt`。
- 详情弹窗仍展示完整账号 JSON，不改变后端数据和接口。

## 验收

- 长字段在主表中不会撑开整列，而是按最大长度截断。
- 仅超长且非空的字段显示“复制”按钮。
- 点击“复制”后可复制该字段完整原始值。
- 公开验证码 URL 的原有复制入口保持不变。

## 回滚

回滚 `web/app.js`、`web/styles.css` 和对应测试改动即可恢复原始完整展示方式；无需数据库迁移或数据清理。
