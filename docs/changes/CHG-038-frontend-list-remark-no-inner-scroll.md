# CHG-038 前端列表取消局部竖向滚动并显示补号备注

状态：implemented
创建日期：2026-06-05
关联 PRD：PRD-002
关联 Issue：
影响范围：`web/index.html`, `web/app.js`, `web/styles.css`, `test/replacementAccountsWeb.test.js`, `test/accountsWebApi.test.js`, `docs/work/`

## 背景

用户反馈补号管理和邮箱管理列表区域不应出现内部上下滚动条；补号管理主表当前展示 `SMS 错误`，却看不到管理员备注，不利于日常识别账号。

## 变更内容

- 修改：补号管理主表将 `SMS 错误` 列替换为 `备注` 列，展示 `replacement_accounts.remark`。
- 修改：补号管理和邮箱管理共用表格容器不再设置固定最大高度和纵向滚动，仅保留横向滚动以查看宽表字段。
- 修改：邮箱获取邮件结果列表不再设置内部最大高度和纵向滚动，内容自然撑开页面。
- 保留：`sms_last_error` 数据仍在账号详情 JSON 中可查看，不删除后端字段和接口返回。

## 验收标准

- [x] 补号管理主表不再显示 `SMS 错误` 列。
- [x] 补号管理主表显示 `备注`，能直接看到 `remark`。
- [x] 补号管理和邮箱管理表格区域不出现内部上下滚动条。
- [x] 邮箱邮件结果列表不出现内部上下滚动条。
- [x] 页面本身允许自然上下滚动。
