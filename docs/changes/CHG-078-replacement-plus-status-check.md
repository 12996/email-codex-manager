# CHG-078 补号账号 Plus 状态查询

状态：accepted
创建日期：2026-07-14
关联 PRD：PRD-003
关联 Issue：
影响范围：补号账号状态、IMAP 邮件查询、补号管理页、API 和测试

## 背景

注册成功的补号账号状态为 `registered`，需要通过 OpenAI Plus 订阅确认邮件判断是否已经开通 Plus。

## 变更内容

- 新增只查询 `registered` 账号的 Plus 状态查询服务和批量 API。
- 命中订阅确认邮件后将状态更新为 `plus_active`。
- 未命中或查询失败时保持 `registered`；查询失败记录原因。
- 补号管理页新增“查询 Plus 状态”按钮和结果提示。
- 增加邮件匹配、状态更新、API 和前端回归测试。

## 验收标准

- [ ] 只查询 `registered` 状态账号。
- [ ] 命中指定 Plus 订阅邮件后状态变为 `plus_active`。
- [ ] 未命中时状态保持 `registered`。
- [ ] 查询失败时状态保持 `registered` 并记录失败原因。
- [ ] 页面按钮可以触发批量查询并刷新列表。
- [ ] 共享收件箱中的非目标收件人邮件不会误判账号。
