# CHG-061 Roxy 低风控录制提示词

状态：implemented

创建日期：2026-07-03

关联 PRD：PRD-003

## 背景

实测发现对 OpenAI 登录页注入 JS 监听 DOM 事件会提高触发安全风控/人机检测的概率。后续录制真实登录流程时，需要让 AI 能自主选择最低必要录制权限，默认避免页面注入，同时仍保留足够的 URL、标题、网络和关键状态用于还原流程。

## 变更内容

- 修改 `src/auto/自动化.md`，将原先“注入录制脚本”的提示改为低风控录制提示词。
- 新增录制权限分级：
  - Level 0：只连接并确认状态。
  - Level 1：默认只录 URL/title/network 元数据。
  - Level 2：按需低频截图/状态快照。
  - Level 3：DOM 监听或 JS 注入，默认禁止，必须用户明确允许。
- 明确敏感信息脱敏规则和风控触发后的降级策略。

## 验收标准

- [x] 提示词默认禁止 `page.addInitScript`、页面内 `evaluate` 注入和 DOM 事件监听。
- [x] 提示词允许 AI 自主选择最低必要录制权限。
- [x] 提示词保留可工作的低侵入录制能力：URL、title、网络元数据、低频关键状态。
- [x] 提示词要求只分析用户说“开始”之后的事件。
- [x] 提示词要求敏感信息脱敏。

## 实现记录

实现日期：2026-07-03

## 回滚
