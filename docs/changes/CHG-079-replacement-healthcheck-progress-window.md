# CHG-079 补号状态查询实时进度窗口

状态：implemented
创建日期：2026-07-14

关联 Issue：
影响范围：补号管理页、封禁验活、Plus 状态查询、API 流式响应、测试

## 背景

批量验活和 Plus 状态查询在完成前没有过程反馈，管理员无法确认程序是否仍在执行。

## 变更内容

- 新增共享实时进度窗口。
- “一键验活”和“查询 Plus 状态”通过 SSE 输出账号级处理过程。
- 完成后保留日志和汇总，窗口由用户手动关闭。
- 保留原有 JSON API 行为，兼容现有调用方。

## 验收标准

- [x] 点击两个按钮后立即显示窗口。
- [x] 实时显示开始、读取邮箱、命中/未命中/失败。
- [x] Plus 命中后状态变为 `plus_active`。
- [x] 封禁邮件命中后状态变为 `banned`。
- [x] 完成后窗口保留最终汇总。
- [x] 原有 API 和全量测试通过。
