# CHG-102 精简补号账号操作菜单

状态：implemented
创建日期：2026-07-31
关联 PRD：PRD-003
关联 Issue：
影响范围：补号账号前端操作菜单、前端回归测试

## 背景

补号账号列表的“操作”菜单包含多个不再需要的手动入口，影响日常操作效率。

## 变更内容

- 从操作菜单移除“启用/停用公开验证码”“获取验证码”“获取 JSON”“2FA 登录”和“复制公开验证码 URL”。
- 保留现有前端事件处理、后端 API 和数据字段，不删除相关能力。

## 验收标准

- [x] 账号行操作菜单不渲染上述五项操作。
- [x] 协议注册、协议补号、编辑账号、注册、执行补号、2FA 补号、解除熔断（适用时）和删除账号仍保留。
- [x] 后端接口与其他前端调用路径不变。
