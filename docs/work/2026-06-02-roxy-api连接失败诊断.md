# 2026-06-02-Roxy API 连接失败诊断

- 状态：done
- 目标：定位 `roxy_oauth_login` 的 `fetch failed` 原因，并增强错误信息，便于后续快速判断 RoxyBrowser API 配置问题。
- 修改文件：`src/auto/roxy-browser-client.cjs`、`test/roxyBrowserClient.test.js`、`docs/changes/CHG-009-roxy-api-fetch-diagnostic.md`、`docs/work/`
- 诊断结论：
  - `.env` 中 `ROXY_API_BASE_URL=http://127.0.0.1:50000`。
  - 本机 `127.0.0.1:50000` 未监听，`Test-NetConnection` 返回失败。
  - RoxyBrowser 进程存在，但未看到 `50000` API 监听端口；当前失败发生在 `/browser/list` 解析窗口阶段，尚未进入 OAuth 页面导航。
- 实现内容：
  - `RoxyBrowserClient.request()` 对原生 `fetch` 失败增加包装错误，输出请求方法、完整 URL、底层原因和配置检查提示。
  - 新增测试覆盖 `ECONNREFUSED` 场景。
- 验证结果：
  - `node --test test\roxyBrowserClient.test.js` 通过。
  - 复跑 `node src\auto\roxy_oauth_login.js` 后，错误已显示为 `Roxy API 请求失败: GET http://127.0.0.1:50000/browser/list?...; 原因=ECONNREFUSED 127.0.0.1:50000`。
- 未完成 / 风险：
  - 真实连接仍需在 RoxyBrowser 中启用 API，或把 `.env` 的 `ROXY_API_BASE_URL` 改成实际监听的 Roxy API 地址。
