# 2026-06-06 Windows 3000 端口 EACCES 修复

## 背景

用户执行 `npm start` 启动服务时报错：

```text
Error: listen EACCES: permission denied 0.0.0.0:3000
```

## 排查

- 检查 `src/server.js`：服务默认读取 `process.env.PORT || 3000`。
- 检查本机端口：`Get-NetTCPConnection -LocalPort 3000` 无监听结果。
- 检查 Windows TCP 排除端口：`netsh interface ipv4 show excludedportrange protocol=tcp` 显示 `2987-3086`，3000 位于该范围内。

## 处理

- 在本机 `.env` 中配置 `PORT=3100`。
- 在本机 `.env` 中将 `VERIFICATION_CODE_API_URL` 留空，让 Roxy OAuth / 注册自动化默认按 `PORT` 推导验证码 API URL。
- 更新 `.env.example`、README、部署/API 文档、Roxy OAuth / 注册自动化默认验证码 API URL 和相关测试。
- 新增 change：`docs/changes/CHG-039-avoid-windows-port-3000-eacces.md`。
- 新增 issue：`docs/issues/issue-007-windows-port-3000-eacces.md`。

## 验证

- `npm start` 启动验证：服务输出监听 3100，`http://127.0.0.1:3100/login` 返回 200。
