# 2026-08-04 Codex JWT AT 扩展校验诊断

- 现象：真实扩展页面在本地格式检查通过后显示通用“AT 校验失败”。
- 已确认：原 controller 将 JWKS 请求、签名校验和 claim 校验的所有异常合并为同一条通用提示，因此页面无法区分失败原因。
- 环境证据：本机执行公开 JWKS URL 的无凭证连接测试超时；这提示需要优先检查浏览器到 `chatgpt.com` 的网络、代理或防火墙，但终端网络结果不能单独证明 Chrome 的结果。
- 修改：新增不含 JWT 或原始错误的失败分类：JWKS 获取失败、签名不匹配、Agent Identity claim 不匹配；未知错误仍保持通用提示。
- 验证：定向 controller 测试覆盖 HTTP/JWKS 请求失败、claim 失败、签名失败和敏感错误不泄露。
- 待用户验收：重新加载未打包扩展后重试；只反馈页面显示的分类文字，不发送 JWT。
