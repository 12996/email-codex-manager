# Roxy 低风控录制提示词

下次需要录制真实登录/注册流程时，直接复制下面这段给 AI 使用。

```text
打开 Roxy 浏览器 profile：gpt，SN: 617-8。

这是一个高风控登录流程录制任务。你必须自己选择最低必要权限，目标是“不触发风控，同时保留足够信息用于后续还原自动化流程”。

硬性边界：

1. 默认禁止向页面注入 JS。
   - 禁止 page.addInitScript。
   - 禁止 page.evaluate 注入 addEventListener / hook fetch / hook XHR。
   - 禁止读取或修改 localStorage、sessionStorage、cookie、token、页面全局对象。
2. 默认禁止 DOM 事件监听。
   - 不监听 click/input/change/keydown。
   - 不记录精确输入内容。
   - 不自动点击、输入、提交登录表单。
3. 默认只允许低侵入浏览器外部录制：
   - CDP/Playwright 连接现有 Roxy 浏览器。
   - 记录主 frame URL 跳转、页面标题。
   - 记录非静态网络请求/响应元数据：method、resourceType、status、脱敏 URL。
   - 必要时低频记录页面状态或截图；不要高频轮询。
4. 敏感信息必须脱敏：
   - URL query 中 token/code/otp/pass/secret/mfa/challenge/state/nonce 等参数替换为 <redacted>。
   - headers 中 authorization/cookie/set-cookie/token/secret 替换为 <redacted>。
   - 密码、验证码、access token、refresh token 不得输出明文。

权限分级由你自动选择：

- Level 0：只连接浏览器并确认页面状态，不开启任何录制。
- Level 1（默认）：只录 URL/title/network 元数据和少量 heartbeat；不注入 JS，不监听 DOM。
- Level 2：仅在我明确要求“需要截图”时，手动采集关键页面截图/可访问性快照；保持低频。
- Level 3：DOM 事件监听或页面 JS 注入。默认禁止。只有我明确说“允许注入 JS/允许监听 DOM”，并且你先提醒风控风险后，才可以临时启用；一旦出现人机验证或异常风控，立即停止并降回 Level 1。

流程：

1. 先打开并连接 Roxy profile。
2. 说明你选择的录制 Level 和原因。
3. 如果是 Level 1/2，启动不注入 JS 的被动录制。
4. 等我说“开始”后再创建 start 标记；只分析“开始”之后的事件。
5. 我会手动操作页面；完成后我会说“完成了”。
6. 完成后停止录制，整理：
   - 跳转顺序；
   - 关键页面状态；
   - 关键网络请求；
   - 我口头标注的操作节点；
   - 与现有自动化代码的差异。
7. 如果我要求，再把差异整理成 Playwright 自动化代码；不要因为录制不足就补充高风险注入。

如果你发现我要求的录制方式会明显增加风控风险，优先降级权限并说明会损失哪些信息，而不是直接执行高风险录制。
```

## 使用说明

- 录制登录/注册类页面时，默认用 Level 1。
- 想知道精确 selector 时，优先等流程结束后通过页面结构、截图和现有代码推断；不要在真实登录过程中注入 DOM 监听。
- 如果已经注入过 JS 并触发风控，先停止注入录制器，再刷新或重新打开登录页，清理当前文档上下文。
